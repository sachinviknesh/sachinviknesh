# TrueShield AI (Vite + React + TS)

Run locally:

```
npm install
npm run dev
```

Key routes:
- `/` Home/Landing
- `/features` Features
- `/pricing` Pricing (currency selector)
- `/contact` Contact form
- `/login` Login (demo)
- `/dashboard` Dashboard hub
- `/live` Live View
- `/alerts` Alerts with Email Report
- `/health` Camera Health with Email Report
- `/settings/custom-camera` Custom Camera Settings
- `/ai/customization` AI Camera Customization (add/edit IPs)
- `/women-safety` Women Safety Panel
- `/ceo` CEO Control Panel (fingerprint gate)
- `/crew-motion` Crew Motion Monitor

Tech:
- React 19, TypeScript, Vite 7
- Tailwind CSS 4
- React Router 6

Note: Email sending is mocked via `src/services/email.ts` and logs to console.
